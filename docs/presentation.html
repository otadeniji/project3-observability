Project presentation

Intelligent Observability & Event Watchdog

An API-first monitoring service that turns raw application logs into stored history, statistical signals, and actionable alerts.

The problem

Logs contain signals. Incidents need decisions.

Without a watchdog

  • Manual review is slow during incidents.
  • Signals are difficult to compare over time.
  • Alert history is disconnected from the logs.

With this MVP

  • Upload through a documented API.
  • Build a reusable metric history.
  • Detect spikes and persist the response.
Architecture

One path from event to action.

Log file → FastAPI upload → parser → SQLite records → moving average and standard deviation → anomaly → alert → simulated webhook → Streamlit dashboard

Built with Python, FastAPI, SQLAlchemy, SQLite, NumPy, and Streamlit.
